# ❤️ Valentine's Day Special Project

A personalized, interactive web experience created with love for my favorite person. This project features interactive heart reveals, a memory gallery, and a playful "Will you be my Valentine?" invitation.

## ✨ Features
* **Heart Reveal:** 4 custom-styled hearts that reveal why she's special when tapped.
* **Memory Gallery:** An interactive "picture frame" that cycles through our favorite photos.
* **The "Runner" Button:** A "No thanks" button that playfully avoids being clicked (because "No" isn't an option! 😉).
* **Digital Love Letter:** A soft, aesthetic poem/letter section.
* **Responsive Design:** Optimized for mobile viewing so it looks great on a phone.

## 🛠️ Built With
* **HTML5** - Structure and content.
* **CSS3** - Custom styling, grid patterns, and heart-shaped clip-paths.
* **JavaScript** - Interactive logic for image swapping and the moving button.

### 🛠️ Local Setup
If you want to run this locally:
1. Clone the repository.
2. Ensure `image1.jpg`, `image2.jpg`, `image3.jpg`, and `image4.jpg` are in the root folder.
3. Open `index.html` in any modern web browser.
